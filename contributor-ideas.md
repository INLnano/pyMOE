# pyMOE Project Ideas

This repository contains some proposed project ideas for **pyMOE**, a Python framework for physical optics simulations, numerical light propagation, and emerging optical AI architectures.

The projects are grouped by **difficulty and expected workload** and span topics including visualization, documentation, testing, high-performance computing, lithography workflows, and optical machine learning.

We are open to any suggestion for contribution beyond these ideas!

---

## Beginner Projects – Small (90 hours)

### 1. Visualization (Plotting) for Propagators and Ensemble Propagation

**Description**  
Simulating the optical response of an optical element using a physical optics approach implemented in **pyMOE** results in an electric field defined in space coordinates. pyMOE currently provides mostly 2D visualization tools for inspecting these fields at observation screens in 3D space.

Adding **3D visualization capabilities** will significantly improve understanding of complex optical fields such as vortex beams or Laguerre–Gaussian modes generated by spiral phase plates and related optical elements.

**Task Ideas**
- Improve the quality and user-friendliness of existing visualization tools
- Evaluate compatibility with external visualization tools such as **ParaView**
- Develop enhanced visualization using **matplotlib**, **PyVista**, or similar libraries

**Expected Results**
- Familiarization with pyMOE propagation and simulation frameworks
- Assessment of current visualization usability
- Benchmark current matplotlib-based visualization workflows
- New or improved 2D/3D visualization capabilities

**Requirements**
- Python programming
- Willingness to learn visualization tools such as ParaView or PyVista

**Educational Value**  
Students will develop skills in visualizing large scientific datasets, a highly transferable skill across research and industry.

### 2. Improving Documentation and User Friendliness

**Description**  
The pyMOE framework is described in a *Computer Physics Communications* publication and supported by Jupyter-notebook-based documentation available at:

- https://pymoe-doc.readthedocs.io  
- https://www.sciencedirect.com/science/article/pii/S0010465524002546

Some material from the publication is missing in the documentation, and ongoing development requires restructuring and extending the tutorials.

**Task Ideas**
- Simplify and reorganize existing documentation
- Extend Jupyter notebook tutorials for new features under development  
  (e.g. https://github.com/INLnano/pyMOE/pull/49)

**Expected Results**
- More intuitive and beginner-friendly documentation
- Updated documentation pages aligned with current and future releases

**Requirements**
- Python programming

**Educational Value**  
Students will gain experience in technical communication and reproducible documentation using Jupyter notebooks.

## Intermediate Projects – Medium (175 hours)

### 1. Faster Computation with Fully Parallel Propagations

**Description**  
pyMOE currently supports parallelization for Rayleigh–Sommerfeld propagation using **Dask**, but other propagators (e.g. Bluestein, Angular Spectrum Method) lack parallel implementations.

**Task Ideas**
- Profile code to identify computational bottlenecks
- Implement parallel propagation using **Dask** and/or **JAX**
- Benchmark performance gains

**Expected Results**
- Parallelized propagation framework
- Quantitative performance comparisons with baseline implementations

**Requirements**
- Python programming
- Understanding of parallel processing
- Experience with Dask and/or JAX
- Access to multi-core CPUs or GPUs is advantageous

**Educational Value**  
Students gain hands-on experience in high-performance scientific computing.

---

### 2. Memory Handling for Classes and Objects

**Description**  
pyMOE relies heavily on meshgrid-based data structures that can consume large amounts of RAM, especially for ensemble propagation and high-resolution simulations.

**Task Ideas**
- Profile memory usage of existing classes
- Redesign workflows to use **Dask arrays** or **JAX arrays**
- Reduce memory footprint for large-scale simulations

**Expected Results**
- Memory-efficient implementations supporting simulations with over 1 billion pixels
- Benchmarks comparing memory usage before and after optimization

**Requirements**
- Python programming
- Dask and/or JAX

**Educational Value**  
Students will learn memory profiling and optimization techniques crucial for scalable scientific software.

---

### 3. Migration from `gdspy` to `klayout` and/or `gdsfactory`

**Description**  
pyMOE currently uses **gdspy** for GDS file generation, but gdspy is no longer actively maintained. Migration to **klayout (pya)** or **gdsfactory** is required.

**Task Ideas**
- Identify gdspy dependencies in the codebase
- Replace functionality using klayout or gdsfactory
- Maintain or improve performance and usability

**Expected Results**
- Refactored GDS export code
- Jupyter notebook tutorials demonstrating mask generation and export

**Requirements**
- Python programming
- Familiarity with GDS layouts is a plus

**Educational Value**  
Students gain valuable experience with lithography file formats used in photonics and semiconductor industries.

## Advanced Projects – Large (300 hours)

### 1. Loss Function Engineering for Optical AI Image Recognition

**Description**  
pyMOE is expanding to design and simulation of optical elements for **Optical AI**, where each optical element will work as a neural network layer, whose weights are updated during a training operation, to minimize a loss function. The current development of version 2  (https://github.com/INLnano/pyMOE/pull/49 ) comprises the use of this optical AI framework for recognition of hand-written digits. However, the training is dependent on the choice of the loss function. The engineering of the loss function is important to maximize the learning and obtain the most accurate image recognition.

**Task Ideas**
- Study existing loss functions used in optical AI
- Design custom loss functions adapted to optical computing constraints
- Integrate loss functions into **JAX-based** training pipelines

**Expected Results**
- New loss functions for optical image recognition
- Benchmarks comparing recognition accuracy

**Requirements**
- Python programming
- Machine learning experience
- JAX

**Educational Value**  
Students will work at the intersection of optics, physics, and machine learning.

---

### 2. Optical AI for Real-Life Object Identification

**Description**  
pyMOE is expanding to design and simulation of optical elements for optical AI, where each optical element will work as a neural network layer, whose weights are updated during a training operation, to minimize a loss function. The current development of version 2  (https://github.com/INLnano/pyMOE/pull/49 ) comprises the use of this optical AI framework for recognition of hand-written digits. The next frontier will comprise image recognition of real objects. This more complicated task will concern the development of a strategy for robust classification, which might consider the use of fourier transform for feature extraction and/or edge detection. 


**Task Ideas**
- Integrate Fourier-domain or edge-based feature extraction
- Train optical AI models on real-world datasets
- Evaluate robustness and accuracy

**Expected Results**
- Working object recognition models
- Accuracy benchmarks for classification and localization

**Requirements**
- Python programming
- Machine learning frameworks
- JAX

**Educational Value**  
Students will explore cutting-edge optical computing approaches for real-world vision problems.

---

### 3. Numerical Light Propagation Algorithms: Benchmarks and Tests

**Description**  
pyMOE version 2 introduces several numerical propagation algorithms, such as Bluestein and Angular Spectrum Method propagators, that require careful validation against theoretical models. These algorithms must be carefully crafted to ensure correct propagation at a defined output pixel size.  For this the algorithms need to be assessed in terms of algorithmic operations and validated in terms of theoretical layout. Particular attention will be paid to correct handling of sampling and output pixel size. 


**Task Ideas**
- Study theoretical foundations of numerical propagation
- Validate implementations against analytical solutions
- Design accuracy and performance benchmarks

**Expected Results**
- Verified and validated propagation algorithms
- Quantitative comparisons of accuracy and efficiency

**Requirements**
- Python programming
- Background in numerical optics is advantageous

**Educational Value**  
Students will gain deep experience in computational optics, numerical analysis, and scientific software validation.
